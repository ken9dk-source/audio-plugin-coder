# TranceEQ — Creative Brief

**Source:** PDF *"Design af EQ-Plugin til Trance Leads, Plucks og Midbasses"* (2026).

## Vision
A focused, genre-aware parametric EQ for trance production. The user first chooses **what they are
working on** — a **Lead**, a **Pluck**, or a **Midbass** — and the plugin lays out a sensible EQ
tailored to that sound (frequencies, Q and gains from the reference table in the PDF). From there the
producer fine-tunes by dragging the curve.

Two pillars from the PDF:
1. **Musical correctness** — IIR biquad bands (RBJ Audio-EQ-Cookbook), plus optional **key-tracking**
   so chosen peak bands "surf" the played note (à la SoundRadix SurferEQ / iZotope Follow-EQ).
2. **Neuroinclusive UX** — calm, *muted* low-stimulation palette, clearly sectioned layout, and a
   **Focus Mode** that hides advanced controls behind a simple set of macros. (ADHD/autism-friendly.)

## Headline features (must-have, from PDF)
- Parametric EQ bands for **Lead / Pluck / Midbass** (HPF, low-shelf, peak, high-shelf, LPF).
- **Mode selector** that reconfigures the bands for the selected sound — *"choose what you work on"*.
- **Real-time spectrum analyser** with peak-hold, overlaid with the live EQ response curve.
- **Key-tracking mode** — bands lock to the played note via **audio pitch detection or MIDI**.
- Calm, **ADHD-friendly UI** with **Focus Mode** (Basic ⇄ Advanced) and muted colours.

## Deferred (nice-to-have, noted in PDF)
Linear-phase mode, oversampling, sidechain pitch input, auto-EQ-match, ARA.

## Theme
**Midnight blue + teal** — dark blue-grey background, soft desaturated teal/cyan accent. Low eye-strain.
